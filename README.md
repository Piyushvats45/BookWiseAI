# BookWise AI

Upload your own PDFs (books, papers, notes, docs) and ask questions about them. Answers are generated by an LLM from the passages retrieved out of *your* document, and every answer cites the book and page it came from.

**Stack:** Java · Spring Boot · Spring AI · PostgreSQL + pgvector · React  · Vite · Tailwind CSS 

## How it works

```
Upload PDF ──► validate (header, size, pages, not encrypted, parseable)
           ──► store file + book row (status PROCESSING), return 202
           ──► async: extract text page by page (PDFBox)
           ──► split each page into ~500-token chunks (TokenTextSplitter)
           ──► embed chunks (OpenAI text-embedding-3-small, 1536 dims)
           ──► store in pgvector with metadata {user_id, book_id, book_title, page_number}
           ──► status READY

Ask question ──► embed question
             ──► similarity search in pgvector (cosine, topK 6, threshold 0.25),
                 filtered by user_id AND book_id
             ──► numbered excerpts + recent chat history ──► LLM
             ──► answer in Markdown with [n] markers
             ──► citations = the excerpts the answer actually referenced (title, page, snippet)
```


## API

All routes except register/login need `Authorization: Bearer <token>`.

| Method | Path | Notes |
|---|---|---|
| POST | `/api/auth/register`, `/api/auth/login` | Returns `{ token, user }` |
| GET | `/api/auth/me` | Current user |
| GET | `/api/books` | Your library |
| POST | `/api/books` | Multipart `file`; returns 202 while indexing continues |
| GET | `/api/books/{id}` | Poll `status`: `PROCESSING`, `READY`, `FAILED` |
| GET | `/api/books/{id}/file` | Original PDF (used to open a cited page) |
| DELETE | `/api/books/{id}` | Removes file, vectors and chat history |
| POST | `/api/books/{id}/chat` | `{ "question": "..." }` returns the answer with `citations[]` |
| GET / DELETE | `/api/books/{id}/messages` | Read / clear chat history |
